# pinkiecmd
💕A lightweight script to give your Linux terminal a pink makeover.

## Preview

![Image](2.png)


## Install

```bash
git clone https://github.com/nwyra/pinkiecmd.git
cd pinkiecmd
chmod +x install.sh
./install.sh
```
option 1 : Restart terminal
option 2 : Run : `source ~/.bashrc` / `source ~/.zshrc`

## Uninstall

```bash
chmod +x uninstall.sh
./uninstall.sh
```

Restart your terminal.
